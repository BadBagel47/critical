# Critical ST8

A co-op space game for up to three players who share one ship. Fly, fight, dock and board wrecks and stations for fuel, credits and star charts. It can also be played solo.

An early solo build is playable at https://badbagel47.github.io/critical/. Fly the frigate, fight pirates, manage power and repairs, dock with wrecks and stations, board them, buy upgrades and jump between five sectors to reach the pirate cruiser. To run it locally, serve the folder with `npm run serve`.
