# Critical ST8

A co-op space game for up to three players who share one ship. Fly, fight, dock and board wrecks and stations for fuel, credits and star charts. It can also be played solo.

An early solo build is playable: fly the frigate, fight pirates, manage power and repairs, switch between the three posts and dock with wrecks. Open `index.html` through a web server, for example `npm run serve`.
